# Runbook: Revertir un despliegue

**Plataforma:** Cloudflare Pages.

1. Abre el proyecto en Cloudflare Pages y localiza el último despliegue correcto.
2. Vuelve a desplegar esa versión o revierte el cambio en `main`.
3. Comprueba que el sitio carga y que los enlaces de WhatsApp, teléfono y correo son correctos.
4. Envía un mensaje de prueba mediante Formspree.
5. Registra el incidente en [`.ai/BUGS.md`](../../.ai/BUGS.md) si corresponde.
